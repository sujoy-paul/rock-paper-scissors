# rock-paper-scissors

A simple Rock Paper Scissors game.

## Built With

* HTML
* CSS
* JavaScript

## Features

* Play Rock, Paper, Scissors against the computer
* Randomised computer choices
* Live score tracking
* Round result display
* First player to reach 5 points wins
* Game automatically ends when a player reaches 5 points

## What I Learned

* Using JavaScript to manipulate the DOM
* Handling user interaction with event listeners
* Using event delegation
* Generating random values with `Math.random()`
* Working with game state using variables
* Updating HTML content dynamically
* Using CSS Flexbox for layout
* Styling and structuring a basic interactive webpage
